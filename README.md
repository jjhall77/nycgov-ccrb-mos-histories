# nycgov-ccrb-mos-histories

> Independent daily archive of CCRB Member-of-Service records, maintained by
> John Hall for research use. Continuation of the public archive originally
> run by Ryan Watkins (scraper code MIT, see LICENSE) after the original repos
> were deleted in July 2026. Unlike its predecessors, this repo also archives
> `officers.csv` — the full NYC Open Data officers payload (race, gender,
> last-reported-active date, complaint totals) that `officers.json` strips.

History of [CCRB complaint records](https://www1.nyc.gov/site/ccrb/policy/MOS-records.page)
from nyc.gov/ccrb and opendata.cityofnewyork.us
